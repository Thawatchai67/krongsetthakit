# กรองเศรษฐกิจ

เว็บอ่านและกรองข่าวเศรษฐกิจ ไทย + ต่างประเทศ แล้วโยงสัญญาณจากข่าวไปยังกลุ่มหุ้นไทย (SET) และหุ้นสหรัฐ
**ไม่ใช้ AI และไม่ใช้ token** ทุกอย่างเป็นกฎที่แก้ไขเองได้

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `config/feeds.json` | รายการแหล่งข่าว RSS (เปิด/ปิด/เพิ่มได้) |
| `config/rules.json` | หมวดข่าว + คีย์เวิร์ด + สัญญาณ (เช่น น้ำมันขึ้น, ลดดอกเบี้ย) + หุ้นที่โยงกับสัญญาณ |
| `scripts/fetch_news.py` | ดึง RSS → กรอง → จัดหมวด → ตัดข่าวซ้ำ → เขียน `docs/news.json` |
| `docs/index.html` | หน้าเว็บ (อ่าน `news.json`) |
| `.github/workflows/update.yml` | รันทุกชั่วโมงอัตโนมัติบน GitHub Actions |
| `tests/` | ทดสอบกฎแบบออฟไลน์ |

## ใช้งานบนเครื่อง

```bash
pip install -r requirements.txt
python tests/test_rules.py          # ทดสอบกฎ
python scripts/fetch_news.py        # ดึงข่าวจริง -> docs/news.json
cd docs && python -m http.server 8000   # เปิด http://localhost:8000
```

ทดสอบแบบไม่ต่อเน็ต: `python scripts/fetch_news.py --from-dir tests/samples --out /tmp/news.json --no-merge`

## ขึ้นเว็บฟรี (GitHub Pages)

1. สร้าง repo บน GitHub แล้วอัปโหลดทุกไฟล์
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, โฟลเดอร์ `/docs`
3. แท็บ Actions → "อัปเดตข่าว" → Run workflow (หลังจากนั้นรันเองทุกชั่วโมง)

## ปรับกฎเอง

- เพิ่มหมวดหรือคีย์เวิร์ดใน `categories` ข่าวจะถูกเก็บเมื่อคะแนนถึง `min_score`
  (คำในหัวข้อข่าวให้ 3 คะแนน คำในเนื้อข่าวให้ 1 คะแนน สูงสุด 2)
- คำภาษาอังกฤษต้องตรงทั้งคำ ไม่สนตัวพิมพ์ ใส่ `cs:` นำหน้าถ้าต้องการสนตัวพิมพ์ (เช่น `cs:AI`)
- เพิ่มสัญญาณใน `signals` โดยเขียน regex ใน `patterns` และกลุ่มหุ้นใน `impacts`
- แก้แล้วรัน `python tests/test_rules.py` เพื่อเช็กว่ากฎไม่พัง

## ข้อจำกัดที่ควรรู้

- สัญญาณมาจากการจับคู่คำในหัวข้อ/เนื้อข่าว อาจพลาดหรือจับผิดได้ (เช่น ข่าวบริษัทน้ำมัน "กำไรเพิ่มขึ้น" ไม่ใช่น้ำมันขึ้น)
- การโยงสัญญาณกับหุ้นเป็นหลักทั่วไป ไม่ใช่การวิเคราะห์รายตัว และยังไม่ได้ดึงราคาหุ้น/ตัวชี้วัดพื้นฐาน
- RSS บางแหล่งอาจเปลี่ยน URL หรือบล็อกการดึง ถ้า feed ใดพัง หน้าเว็บจะแสดงชื่อ feed ที่ดึงไม่ได้ในแถบแจ้งเตือน
- เป็นข้อมูลประกอบการตัดสินใจ ไม่ใช่คำแนะนำการลงทุนโดยผู้ได้รับใบอนุญาต
